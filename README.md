# LearnHub+

An online learning platform built with ReactJS.

## Project Description

LearnHub+ is a frontend web application that allows users to browse online courses, learn about the platform, explore available services, and contact the team. The platform is fully responsive and works on both desktop and mobile devices.

## Pages

- Home: landing page with course cards and stats
- About: information about the platform, mission and team
- Services: list of all services offered
- Contact: contact form with validation

## Technologies Used

- ReactJS
- React Router DOM
- CSS

## Setup Instructions

1. Make sure you have Node.js installed on your computer
2. Download or clone the project folder
3. Open a terminal inside the project folder
4. Run: npm install
5. Run: npm start
6. The app will open at http://localhost:3000
